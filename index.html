Questions, answered.

Is it safe to point this at my real library?

Yes — that's the design constraint everything else serves. Originals are never re-encoded, risky operations snapshot first, writes to your iCloud system library go through Apple's own PhotoKit, and destructive actions have working undo.

Does it work with iCloud Photos?

Yes. Your system library keeps syncing normally — changes made through SyncMyLibs propagate to your other devices the same way Photos' own changes do. Offline libraries on external drives work too.

Why does it need Full Disk Access?

Photos libraries other than your system library live behind macOS file protections. Full Disk Access lets SyncMyLibs open them directly — it's the same requirement any multi-library tool has, and the app asks once with an explanation.

Which Macs does it run on?

macOS 15 (Sequoia) or later on Apple silicon. It's a native Swift app — no Electron, no web views.

How much will it cost?

One-time purchase, priced at launch — no subscription. Updates arrive in-app.
